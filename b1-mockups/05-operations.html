Delivery + operations · P10–P12 · H5/H6

Live — and on a leash

Production is static JSON on Cloudflare R2 behind a CDN — the only API is GET. Devices refresh the channel manifest on foreground (and a 6-hour timer) and pull artifacts lazily through hash + signature verification. When a module misbehaves, containment is layered: the error boundary catches it on-device, the circuit breaker stops retries after 3 strikes, and modctl kill removes it from every user within one foreground cycle. Rollback is repointing the manifest at a previous immutable artifact — no rebuild.

The registry is a bucket

Source of truth is the hearthlabs/registry git repo; publish.yml syncs merged manifests to R2. Artifacts are immutable and content-addressed (B3) — “versions” exist only in manifests.

Documented MVP gap (§7): the manifest itself is TLS-protected but unsigned — a CDN-level attacker could flip kill flags or hide modules (availability only; code injection stays blocked because artifacts are ed25519-signed against the pinned pubkey). manifest signing is the first Phase-2 line item.

One device, one foreground cycle

The same ~500-line loader from the dev shell, now on an end user's phone. Loader overhead with zero modules is <50 ms on a mid-range device (H10); modules evaluate lazily on first navigation to their mount.
