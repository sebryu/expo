A module is born

The owner writes a FEATURE_SPEC.md, then scaffolds a fresh repo from the GitHub template hearthlabs/module-template. The agent that takes over gets a typed SDK, edit-time import-boundary lint, a Tier-1 test harness, and the full verify.yml pipeline preinstalled — and zero credentials for the host repo. Core protection is GitHub permissions, nothing cleverer.

What the template hands the agent

module.json manifest · validated by ajv (P4) + host loader 
{
  "id": "weather-widget",
  "version": "0.1.0",
  "entryPoint": "index",
  "requiredSdkVersion": "^1.0.0",
  "capabilities": [
    "navigation",
    "storage.scoped",
    "events",
    "network",
    "theme"
  ],
  "mounts": [
    "route:home/weather",
    "slot:home.cards"
  ]
}

// hash · signature · keyId are appended at publish time (P9),
// never written by the agent. rollout/cohorts stay reserved (B5).
src/index.tsx typed against @app/sdk-types 
import React from 'react';            // external → host singleton via __hostRequire__
import type { ScopedSdk, ModuleExports } from '@app/sdk-types';

type Caps = 'navigation' | 'storage.scoped' | 'events' | 'network' | 'theme';

function WeatherCard({ sdk }: { sdk: ScopedSdk<Caps> }) {
  // sdk.theme, sdk.storage, sdk.network — only requested groups exist;
  // a Proxy throws a descriptive error on anything else (R3).
  return <sdk.ui.Card title="Weather" />;
}

function WeatherScreen({ sdk }: { sdk: ScopedSdk<Caps> }) {
  return <sdk.ui.Screen title="Forecast" />;
}

// The bundle's ONLY sanctioned top-level side effect (C4).
// Anything else — network, timers, globals — fails the P4 probe.
globalThis.__registerModule__('weather-widget', (sdk: ScopedSdk<Caps>): ModuleExports => ({
  mounts: {
    'route:home/weather': () => <WeatherScreen sdk={sdk} />,
    'slot:home.cards':   () => <WeatherCard sdk={sdk} />,
  },
}));

Feedback at edit time, not pipeline time

The template's ESLint no-restricted-imports rule allows only @app/sdk plus the pure-JS dependency allowlist (a literal JSON array in the registry repo, Q2). Importing host internals is a red squiggle in the agent's editor — the same config the pipeline runs as P2.

The contract is the interface

tsconfig.json resolves types from @app/sdk-types; host-contract.json (published per host build) pins the exposed mounts and capability groups that P4 validates module.json against. Unknown mounts are a validation failure.

One spec, two readers

FEATURE_SPEC.md drives the feature agent now — and becomes the ground truth the P5 smoke test drives and the P7 behavioral-review agent verifies recordings against. Freeform markdown in MVP (Q6).
