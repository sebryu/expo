Implementation proposal B1 · screen-by-screen walkthrough

Fetch. Verify.
Mount. Kill. Roll back.

B1 — the Pragmatic MVP — optimizes for one number: days until the first AI-built module runs on a real device through the full production loading path. There is no bundler framework and no backend service: each module is an esbuild single-file bundle evaluated with new Function in the host's shared Hermes runtime, resolving host singletons through __hostRequire__. The registry is a git repo synced to Cloudflare R2 — the only read API is GET. Publish, kill, and rollback are a ~400-line modctl CLI plus GitHub Actions; one-click promote is literally clicking Merge on an auto-generated promotion PR. Every artifact is SHA-256 hashed and ed25519-signed against a public key pinned in the binary, and every mount sits behind an error boundary, a 3-strike circuit breaker, and a remote kill flag. Target: ~3 weeks to end-to-end.

The runtime spine

Every channel — localhost dev registry, staging, production — feeds the same ~500-line loader. What an agent sees in the dev shell is exactly what users get.

Externals stay host singletons: a 20-line esbuild plugin rewrites import "react" → globalThis.__hostRequire__("react") — react, react-native, expo-*, and @app/sdk are never bundled twice.  ·  Kill honored within one foreground cycle (H6).  ·  Rollback = repoint the manifest at a previous immutable artifact — no rebuild (P11).

Why this shape

The unit of AI work equals the unit of shipping, verification, and rollback: one module. Agents work in repos scaffolded from a template with no write access to the host repo — core protection is GitHub permissions, nothing cleverer.

Every part is boring and replaceable — GitHub Actions, R2/S3, Sentry, ajv, @noble/ed25519, esbuild, argent MCP. The only durable interface is the contract: manifest + global register function + scoped SDK object.

Honest posture: capability scoping in v1 is a build/review-time convention, not a runtime security boundary. The threat model is buggy AI code and a compromised CDN (TLS + hash + signature) — not malicious authors.
